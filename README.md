# Organizador Financeiro Pessoal

Aplicação web simples para gerenciamento de finanças pessoais, permitindo registrar receitas e despesas, calcular o saldo automaticamente e reter os dados no navegador.

## Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript (ES6+ e manipulação do DOM)
- LocalStorage (persistência de dados no cliente)

## Funcionalidades
- Cadastro de transações com categorização (receita/despesa).
- Cálculo dinâmico de saldo com destaque visual.
- Exclusão individual de registros.
- Persistência das informações via `localStorage`.

## Como executar localmente
1. Clone o repositório:
   git clone https://github.com/brendascruz/organizador-financeiro.git
2. Abra o arquivo `index.html` em qualquer navegador web.
